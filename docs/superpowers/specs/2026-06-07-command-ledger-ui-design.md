# ClipSoul Command Ledger UI 重设计规格

## 目标

将 ClipSoul 的主弹窗、设置页、筛选面板、收藏夹菜单、确认面板、prompt 和按钮状态统一重设计为 Command Ledger 风格。目标是高频剪贴板工具的“弹出即可扫、选、粘贴”，不改变任何功能、快捷键、数据流、粘贴逻辑、滚动逻辑、筛选逻辑、收藏逻辑和设置行为。

本次允许调整排版、主题、颜色、阴影、间距、按钮样式、列表密度、浮层层级和状态反馈。所有实现继续基于现有 Win32、Direct2D、GDI 绘制管线，不引入 Web UI、动画库或重型依赖。

## 产品参考

- Raycast：命令密度高，输入框是第一焦点，列表项强调快速扫描和键盘选择。
- PowerToys Run：轻量、系统工具感强，弹出后不打断当前输入环境。
- Windows 11 原生浮层：低饱和、浅色优先、状态反馈克制，避免网页化装饰。

ClipSoul 不能照搬这些产品。它的核心不是“启动命令”，而是“管理并连续粘贴剪贴板记录”，所以列表高亮、记录类型、收藏夹分组、筛选和回到顶部必须比普通 launcher 更清楚。

## 视觉论点

Command Ledger 是一张精密、低干扰的剪贴板账本：搜索是入口，列表是主体，高亮项像被轻轻抬起的当前记录。整体黑白灰为主，少量冷灰用于背景层级，重点靠字重、细轨、阴影和边框强度表达。

## 信息结构

主弹窗从上到下分为五段：

1. 顶部状态条：品牌、版本、pin、close，视觉权重最低。
2. 搜索区：第一视觉焦点，输入框更宽、更安静，清除按钮只在有内容时明显。
3. 工具区：筛选、多选、清空、多选操作，使用紧凑低矮按钮。
4. 视图切换区：历史和收藏夹使用低矮 segmented tabs，收藏夹附加分组和新增短语入口。
5. 记录账本区：列表项以行卡片为主，当前高亮项通过左侧细轨、抬升阴影和深灰文字突出。

设置页使用两列式设置表单：左侧是设置标签和说明，右侧是输入框、按钮、toggle。减少嵌套卡片，保留清楚分区。

## 颜色系统

浅色模式为主：

- `canvas`: `0xF3F4F6`，窗口底色，冷灰。
- `surface`: `0xFFFFFF`，主面板、输入框和高亮项表面。
- `surface_subtle`: `0xFAFAFB`，普通列表项和次级控件。
- `surface_hover`: `0xF6F7F8`，hover 背景。
- `surface_pressed`: `0xEEF0F3`，pressed 背景。
- `text_primary`: `0x17181A`，主文字。
- `text_secondary`: `0x5F636A`，元信息、说明文字。
- `text_tertiary`: `0x8A8F98`，弱提示。
- `border_subtle`: `0xE1E3E7`，普通分隔线和弱边框。
- `border_strong`: `0xC9CDD4`，focus、选中、浮层边框。
- `accent`: `0x2B2F36`，当前项细轨、主按钮、滚动条拇指。
- `accent_hover`: `0x17181A`，主按钮 hover。
- `danger`: `0xD14343`，删除、清空、关闭 hover。

暗色模式保留，但不是本轮主视觉：

- `canvas_dark`: `0x111214`
- `surface_dark`: `0x1B1C1F`
- `surface_subtle_dark`: `0x23252A`
- `surface_hover_dark`: `0x2B2D32`
- `text_primary_dark`: `0xF1F2F4`
- `text_secondary_dark`: `0xA6AAB2`
- `border_dark`: `0x454850`
- `accent_dark`: `0xD7DCE3`

禁止把蓝色、青色、紫色、橙色作为常规重点色。红色只用于危险动作和关闭 hover。

## 排版

继续使用系统 UI 字体栈，避免额外字体依赖：

- Windows: `Segoe UI`
- CJK fallback: 系统中文字体

字号层级：

- 品牌标题：14px，600。
- 搜索输入：14px，400。
- 记录标题：13px，500。
- 记录元信息：11px 到 12px，400。
- 工具按钮：12px，500。
- 设置页标题：15px，600。
- 设置说明：12px，400。

原则：

- 不使用大标题和营销式文案。
- 动态数字、版本号、时间建议使用等宽数字能力，如果当前绘制管线支持则开启。
- 中文不做负字距。

## 主弹窗布局

### 顶部状态条

顶部高度保持紧凑。`ClipSoul` 品牌不再像标题卡片，而是作为状态标识。版本号放在品牌右侧，使用弱文字。pin 和 close 保持右上角，但按钮默认无填充，hover 才显示浅灰或淡红背景。

### 搜索区

搜索框是第一焦点：

- 宽度占满左右 margin。
- 高度可保持 38px，但视觉上更像一条命令输入行。
- 默认白底、弱边框。
- focus 时边框变强，外层只加轻微黑色阴影，不使用发光。
- 搜索图标和清除按钮使用 `text_tertiary`，hover 后升到 `text_secondary`。

### 工具区

普通模式：

- 左侧筛选按钮显示当前筛选状态。
- 右侧多选、清空按钮保持低矮。
- 按钮默认透明或 `surface_subtle`，hover 使用 `surface_hover`。

多选模式：

- 取消、全选、删除、粘贴保持现有功能。
- 删除使用 danger 语义，但默认不要大红块，hover 或确认动作才增强。
- 粘贴选中使用深灰实心按钮。

### 视图切换区

历史和收藏夹使用低矮 segmented tabs：

- active tab 使用白色抬升面、1px 强边框或 2px 底部短线。
- inactive tab 只有文字，不用大面积填充。
- 收藏夹分组按钮和新增短语按钮是 icon-only 小按钮，默认弱化，hover 才出现圆角底。

### 记录账本区

列表项从“卡片”调整为“账本行卡片”：

- 普通项背景为 `surface_subtle` 或接近透明，边框更弱。
- hover 项背景轻微变亮，并增加非常浅的阴影。
- 当前高亮项使用 `surface`，左侧 3px 深灰细轨，阴影增强，文字权重略高。
- 多选 checkbox 保持原功能，选中时使用深灰填充。
- 类型图标统一灰阶，不再按文本、图片、文件、链接使用多彩分类。
- 图片和文件预览保留，但外框使用中性灰阶。
- 时间和菜单按钮保持右侧，菜单按钮默认弱化，hover 可见。

## 浮层

### 筛选面板

筛选面板从工具栏下方展开，作为紧凑控制面板：

- 背景 `surface`，边框 `border_strong`，轻中等阴影。
- 类型 chip 使用统一灰阶。active chip 用深灰文字、白色抬升面、强边框。
- 日期卡片更像表单控件，减少装饰背景。
- 日历选择使用深灰圆点，日期范围使用浅灰条，不使用彩色范围。
- 完成按钮使用深灰实心，重置为文本或轻边框按钮。

### 收藏夹菜单

收藏夹菜单是窄列表 popover：

- 当前分组使用左侧细轨和 500 字重。
- 分组删除按钮默认弱化，只在 hover 行时明显。
- 新建收藏夹作为最后一行，使用加号图标或弱文字。
- 删除确认面板继续阻断误删，但视觉更克制，危险按钮只在确认动作上使用红色。

### 回到顶部按钮

当记录不在顶部时出现：

- 固定右下角，圆形或近圆形。
- 默认白底、细边框、轻阴影。
- hover 时阴影增强，箭头变深。
- 点击后滚动和高亮都回到顶部，功能保持现状。

## 设置页

设置页重新组织为“设置表单”：

- 顶部：标题、关闭按钮。
- 主体：分区标题和设置行。
- 每行左侧为标签和说明，右侧为控件。
- 快捷键、连续粘贴快捷键、记录数量、存储路径、项目链接、弹窗大小等保持现有功能。
- toggle 使用轨道加圆点，active 为深灰轨道，不使用彩色。
- 保存按钮使用深灰实心，hover 近黑。
- 需要重启生效的提示使用弱灰文字，不做大面积提示卡片。

## prompt 与确认窗口

新增收藏夹、添加常用语、编辑文本等 prompt：

- 使用同一浅灰窗口底和白色输入框。
- 标题 14px 到 15px，说明文字弱化。
- 保存按钮深灰实心。
- 取消按钮白底灰边。
- close hover 保持淡红背景。

## 状态系统

所有可点击元素至少有以下状态：

- default：低对比，保持界面安静。
- hover：背景轻微变化，边框或阴影增强。
- pressed：视觉下沉 1px，阴影收缩。
- active：白色抬升面、强边框、深灰文字或左侧细轨。
- danger hover：淡红背景、红色图标或边框。
- disabled：如果后续出现，使用低透明度灰阶。

动画只使用现有 hover timer 或等效短过渡，目标 80 到 120ms。不做弹性、旋转、发光、持续运动、透明亚克力或大面积 blur。

## 深度系统

使用 4 级深度：

- `level_0`: 窗口 canvas，无阴影。
- `level_1`: 普通输入框、普通列表项，弱边框。
- `level_2`: hover、active tab、小按钮 hover，轻阴影。
- `level_3`: 当前高亮项、popover、确认面板，明显但克制的层叠阴影。

阴影颜色以黑色低 alpha 为主，浅色模式不使用蓝灰阴影。暗色模式优先通过背景亮度差和边框表达层级。

## 半径系统

- 外层窗口：18px。
- 搜索框、设置分区、浮层：12px 到 16px。
- 列表项：8px。
- 小按钮：6px 到 8px。
- 圆形按钮：按几何需要使用 pill。

避免在同一组件组内混用过多半径。

## 代码约束

- 不改变业务逻辑和数据结构。
- 不改变连续粘贴、普通粘贴、高亮下移、滚动、回到顶部、筛选、收藏夹和设置保存行为。
- 不改快捷键注册逻辑。
- 不引入新依赖。
- 不批量删除文件。
- 优先把颜色、metrics、材质策略放入 `PopupLayout` 或局部 helper，减少在 `PopupWindow.cpp` 和 `SettingsWindow.cpp` 中继续扩散硬编码。
- 可以调整 layout metrics 和绘制 rect，但必须同步更新布局测试。
- 保持当前无亚克力、无系统 backdrop 策略。

## 测试计划

需要用测试锁定：

- Command Ledger palette 的关键浅色、暗色 token。
- 窗口材质策略仍禁用亚克力和系统 backdrop。
- 主弹窗 metrics 和关键区域位置符合新布局。
- 搜索、工具栏、tabs、记录列表、回到顶部按钮、筛选面板、收藏夹菜单的 hit test 不丢失。
- 设置页如有可测试 layout helper，则补充；如果仍是 GDI 直接绘制，至少保证构建和现有行为测试通过。

验证命令：

```powershell
cmake --build build --config Debug --target clipsoul_tests
ctest --test-dir build -C Debug --output-on-failure
cmake --build build --config Debug --target clipsoul
cmake --build build --config Release --target clipsoul
```

## 实现顺序

1. 测试先行：新增或更新 Command Ledger palette、metrics、布局和材质策略测试。
2. 调整共享 palette、metrics、半径和阴影 helper。
3. 重排主弹窗顶部、搜索、工具栏、tabs 和列表项。
4. 重绘筛选面板、收藏夹菜单、删除确认、回到顶部按钮。
5. 重绘设置页和 prompt。
6. 构建 Debug、运行测试、构建 Release、启动应用供人工检查。

## 人工验收标准

- 呼出窗口后第一眼能定位搜索框和当前高亮记录。
- 连续粘贴时当前项状态清楚，不依赖彩色提示。
- 列表比上一版更像高频工具，不像营销页或后台管理页。
- 筛选和收藏菜单看起来是同一套系统。
- 设置页更像商务工具设置面板，少卡片嵌套，少装饰。
- 鼠标 hover 有反馈，但不会有塑料感、发光感或动画噪声。
